This build has no interface in it.

The Go side of the plugin is complete and serving. What is missing is the built bundle, which is a separate step because it needs npm.

scripts/build-ui.sh builds it, and scripts/build-pokerplugin.sh builds it and then the binary around it. A release binary reports "ui":"built" on /health; this one reports "placeholder".

This page is committed so that go build ./... works without a JavaScript toolchain, which keeps the Go side buildable and testable on its own. It is not an error — unless you are looking at it in a release.
